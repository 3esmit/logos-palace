# Support

Logos Palace is an experimental public-testnet MVP. No production support,
uptime, recovery, or response-time commitment is offered.

## Where to ask

- Usage, build, or integration question: open a GitHub Discussion if enabled;
  otherwise open an issue marked as a question.
- Reproducible defect: open a bug report with the affected commit, expected
  behavior, actual behavior, and minimal non-sensitive logs.
- Feature proposal: open a feature request explaining the user-visible need
  and affected architecture boundary.
- Security vulnerability: follow [SECURITY.md](SECURITY.md). Never disclose it
  in a public issue.
- Contributor workflow: see [CONTRIBUTING.md](CONTRIBUTING.md).

Before requesting help, reproduce against the pinned dependencies in
`flake.lock` and state which Basecamp acceptance gate, if any, was run. Remove
credentials, recovery phrases, private keys, personal data, and unrelated
local paths from logs.
